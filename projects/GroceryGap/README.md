# Examining the Landscape of Grocery Stores in Chicago and Their Relationship to Food Accessibility and Inequality

This project examines the grocery store landscape in Chicago and explores how shifts in the city’s food retail environment relate to neighborhood composition, food accessibility, and inequality.

## Repository Contents

- `Data_and_State_Microproject.ipynb`  
  Main Jupyter notebook containing the data cleaning, analysis, visualizations, and discussion for the project.

- `Historical SNAP Retailer Locator Data 2005-2025.csv`  
  Dataset containing historical SNAP retailer locations used to analyze grocery store distribution and change over time in Chicago.

- `README.md`  
  Overview of the project and repository structure
